# 레조넌스 딜 미터

> [!WARNING]
> 이 도구는 실행 중인 게임의 메모리를 읽습니다(읽기만 하고 쓰기·코드 주입·파일 변경은 하지 않음).
> 

## 사용법

**[resonance-dps-meter.zip](https://github.com/ohsangyun/resonance_dps_meter/raw/main/resonance-dps-meter.zip)** 하나만 받아 풀면 됩니다.

1. 게임을 켭니다.
2. `딜미터 실행.bat` 을 더블클릭합니다.
3. 전투가 끝나면 그 기록을 눌러 **서버 전송**을 누릅니다.

끌 때는 창을 닫으면 됩니다.

## 기록

- 기록은 `logs` 폴더에 쌓이고 계정 식별자(uid·닉네임)는 들어가지 않습니다.
- 서버로는 **서버 전송**을 누른 기록만 갑니다.
