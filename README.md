# 레조넌스 딜 미터

레조넌스: 솔스티스(한국 서버) 전투 기록 도구입니다. 전투마다 피해·비용·카드 사용·버프·편성을 파일 하나로 남깁니다.

## 쓰는 법

1. **Code → Download ZIP** 으로 받아 압축을 풉니다.
2. 게임을 켜고 `딜미터 실행.bat` 을 더블클릭합니다. 작은 창이 뜨면 바로 기록 대기 상태입니다.
3. 전투를 합니다. 끝날 때마다 `logs` 폴더에 `날짜-시각.json` 이 생깁니다.

## 기록 보내기

[Issues](https://github.com/ohsangyun/resonance_dps_meter/issues/new) 에서 새 글을 열고 `logs` 폴더의 json 파일을 끌어다 놓습니다 (GitHub 계정 필요, 안 올라가면 zip 으로 묶어서).

## 참고

- 게임 메모리를 읽기만 합니다. 게임 파일이나 메모리를 바꾸지 않습니다.
- 기록에 계정 정보(uid·닉네임)는 들어가지 않습니다. 편성과 육성 값은 들어갑니다.
- 사용에 따른 책임은 쓰는 사람에게 있습니다.
- 지원 서버: 한섭. 게임 업데이트 뒤 "버전 불일치"가 뜨면 새로 받아 주세요.
- 윈도우 전용입니다. 파이썬은 들어 있어 따로 설치하지 않습니다.
